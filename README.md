# AI Threat Detection Platform

A full-stack AI-based system that analyzes user text and detects potential threats or toxic content.

## Tech Stack
- Frontend: React
- Backend: Node.js + Express
- AI Service: Flask + Transformers
- Database: MongoDB

## Run Instructions

### 1. Start AI Service
cd ai-service
python app.py

### 2. Start Backend
cd server
npm install
node index.js

### 3. Start Frontend
cd client
npm install
npm start
